# Predictive Analytics Using Historical Data

## Project Overview
This project focuses on analyzing historical sales data and predicting future sales using machine learning. A Linear Regression model is used to identify the relationship between time and sales and generate future predictions.

## Objective
The main objectives of this project are:
- Analyze historical sales data
- Identify sales trends
- Build a predictive model
- Evaluate model performance
- Forecast future sales

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Google Colab

## Methodology
1. Created and loaded historical monthly sales data
2. Visualized the historical sales trend
3. Created time-based features
4. Split the data into training and testing sets
5. Trained a Linear Regression model
6. Predicted sales for the test data
7. Evaluated the model using MAE and R² Score
8. Forecasted sales for future months
9. Visualized actual and predicted sales

## Dataset
The dataset contains monthly historical sales records.

### Main Features
- Month
- Sales
- Month Number

## Model Used
**Linear Regression**

Linear Regression was used to learn the relationship between the month number and sales values and predict future sales.

## Model Evaluation
The model was evaluated using:

- Mean Absolute Error (MAE)
- R² Score

These metrics help measure the accuracy and performance of the prediction model.

## Results
The model generated predictions for the test data and forecasted sales for the upcoming months. The results were visualized using graphs to compare actual and predicted sales.

## Conclusion
This project demonstrates how historical sales data can be analyzed and used for predictive analytics. The model provides a simple approach to forecasting future sales and understanding sales trends.

## Tools
Google Colab was used to develop and execute the Python code.
